# Estudo de caso AWS — Abstergo Industries

**Atividade educacional da DIO com empresa fictícia.** Proposta conceitual de uso de serviços de nuvem; não representa implantação ou economia comprovada em uma empresa real.

[Ler o relatório](modelo-relatorio.md) · [Portfólio](https://github.com/Enzo-Zapparolli)

## Objetivo

Relacionar necessidades de infraestrutura a três serviços AWS e discutir possíveis benefícios operacionais.

| Serviço estudado | Papel na proposta |
| --- | --- |
| Amazon EC2 | Hospedagem de aplicações em servidores virtuais |
| Amazon S3 | Armazenamento de arquivos e backups |
| Amazon RDS | Banco de dados relacional gerenciado |

## Entrega

O arquivo [modelo-relatorio.md](modelo-relatorio.md) descreve o cenário e os casos de uso propostos. Não há código de infraestrutura, ambiente provisionado ou medição de custos neste repositório. Os anexos citados no texto original não estão incluídos.

## Limites da análise

Os benefícios descritos são hipóteses do estudo. Redução de custos depende de dimensionamento, utilização, região e operação; não foi calculada ou validada neste projeto.
